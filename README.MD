# Контрольная работа №2
**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».  
**Проект:** Информационно-туристический портал про "Стерлитамак".  
**Студент:** Собачкин Кирилл.

## Описание
Проект представляет собой информационно-туристический портал о городе Стерлитамак (Республика Башкортостан). Сайт знакомит посетителей с историей основания города, уникальными природными памятниками (Шиханы, реки), архитектурным наследием и выдающимися личностями.

## Практическая работа 9
Выполнена главная страница на Bootstrap-сетке.

**Реализовано:**
- подключение Bootstrap 5.3.3 через CDN;
- подключение файла собственных стилей `css/custom.css`;
- подключение Bootstrap JS Bundle;
- шапка страницы (`header`) с адаптивной структурой;
- навигационная панель (`navbar-expand-lg`);
- hero-блок на сетке `row` и `col-12 col-lg-6` с фото города;
- блок преимуществ / фактов на сетке `col-12 col-md-4`;
- сетка популярных мест на адаптивных колонках `col-12 col-md-6 col-lg-4` с карточками, бейджами и фотографиями;
- подвал страницы (`footer`) с полезными ссылками;
- полная мобильная адаптивность (`col-*`, `g-4`).

## Используемые технологии
- HTML5;
- Bootstrap 5.3.3;
- CSS3;
- Git;
- GitHub.
