# Контрольная работа №2
**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».  
**Проект:** Информационно-туристический портал про "Стерлитамак".  
**Студент:** Собачкин Кирилл.

---

## Описание проекта
Проект представляет собой современный информационно-туристический портал о городе Стерлитамак (Республика Башкортостан). Сайт разработан с применением адаптивной сетки и богатого набора компонентов фреймворка **Bootstrap 5.3.3**.

Портал состоит из 5 полноценных тематических страниц:
1. **`index.html` — Главная страница:** визитная карточка портала с панорамным баннером, туристическим гидом впечатлений «Чем заняться в Стерлитамаке», расширенным блоком статистики «Стерлитамак в цифрах» на 8 показателей и сеткой популярных туристических локаций.
2. **`history.html` — История города:** хроника развития города со времён Ашкадарской соляной пристани (1766 г.), эпохи уездного купечества и советской индустриализации, дополненная интерактивным блоком малоизвестных исторических фактов.
3. **`nature.html` — Природа и архитектура:** галерея уникальных природных памятников (знаменитые Шиханы Торатау, Куштау, Юрактау, реки города), исторической архитектуры (Земская управа, Драмтеатр) и модальное окно с памяткой туристу.
4. **`people.html` — Известные люди:** галерея выдающихся уроженцев Стерлитамака (культура, спорт, медиа) и модальное окно `#modalProposePerson` для предложения новых персоналий с подтверждением отправки `#proposalSuccessModal`.
5. **`contacts.html` — Контакты и справка:** визитные карточки инфоцентра для туристов, краеведческого музея, вокзалов и экстренных служб, блок транспортной доступности, модальное окно обратной связи `#feedbackModal` и подтверждение отправки `#contactSuccessModal`.

## Подключение Bootstrap
В проекте Bootstrap 5.3.3 подключён **локально** без использования внешнего CDN (в соответствии с дополнительным заданием методических указаний №11). Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:
- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключён строго после стилей Bootstrap для корректного переопределения правил каскада.

## Практическая работа 9: Сетка и базовая структура
**Цель:** освоить сеточную систему Bootstrap (Grid System), принципы адаптивной верстки (breakpoints, контейнеры, строки и колонки) и базовую структуру страницы.

**Реализовано:**
- локальное подключение скомпилированных файлов Bootstrap 5.3.3 (`vendor/bootstrap/`);
- подключение файла пользовательских стилей `css/custom.css`;
- адаптивная шапка (`header`) с названием портала и бейджем;
- адаптивная навигационная панель (`navbar-expand-lg`);
- hero-блок на адаптивной сетке `row` и `col-12 col-lg-6` с фотографией центра города;
- информационный блок фактов на сетке `col-12 col-md-4`;
- сетка карточек популярных мест `col-12 col-md-6 col-lg-4` с адаптивными отступами `g-4`;
- фиксированный подвал (`footer`) с контактной информацией и копирайтом;
- полная кроссплатформенная адаптивность для экранов любых размеров (`xs`, `sm`, `md`, `lg`, `xl`).

## Практическая работа 10: Компоненты Bootstrap
**Цель:** изучить и внедрить интерфейсные компоненты Bootstrap, интерактивные элементы на JavaScript и элементы форм для создания полноценного многостраничного веб-сайта.

### Использованные компоненты Bootstrap:

| Компонент | Где применён | Описание и назначение |
|---|---|---|
| **`navbar`** | Все страницы (`index`, `history`, `nature`, `people`) | Единая сквозная панель навигации с брендом, адаптивным гамбургер-меню (`navbar-toggler`) для мобильных устройств и подсветкой активного пункта (`active`). |
| **`breadcrumb`** | `history.html`, `nature.html`, `people.html` | Хлебные крошки для удобной навигации и ориентации пользователя по разделам сайта. |
| **`card`** | Все страницы | Универсальные карточки для структурирования контента: эпохи истории, природные памятники, портреты выдающихся личностей и контейнер интерактивной формы. |
| **`badge`** | `index.html`, шапка всех страниц | Информационные бейджи (`bg-light`, `bg-primary`, `bg-success`) для маркировки контрольной работы и категорий объектов. |
| **`alert`** | `history.html`, `nature.html`, `people.html` | Информационные цветные блоки (`alert-primary`, `alert-success`, `alert-info`) с важными историческими и туристическими заметками. |
| **`modal`** | Все страницы | Всплывающие модальные окна при нажатии кнопок: справка инфоцентра (`#helpModal` в шапке), детальные карточки культурных мест на главной (`#modalMuseum`, `#modalSobor`, `#modalTheater`), хроника дат (`history.html`), памятка туристу (`nature.html`), подробные биографии и подтверждение отправки (`people.html`, `contacts.html`). |
| **`accordion`** | `history.html` | Раскрывающийся интерактивный блок FAQ (`#historyAccordion`) с ответами на интересные вопросы о происхождении названия города, гусях на гербе и подвиге в ВОВ. |
| **`btn`** | Все страницы | Стилизованные кнопки различных вариаций (`btn-primary`, `btn-outline-primary`, `btn-success`, `btn-outline-secondary`, `btn-secondary`) для действий, вызова модальных окон и отправки форм. |
| **`form-control`** | `people.html` | Стилизованные поля текстового ввода (`type="text"`, `type="email"`) и многострочное поле `textarea` в форме добавления земляка. |
| **`form-select`** | `people.html` | Выпадающий список выбора сферы деятельности персоналии (спорт, культура, наука, промышленность, общественная деятельность). |
| **`input-group`** | `people.html` | Составные поля ввода с текстовыми префиксами (`input-group-text`) для ввода ссылки на источник (`https://`) и номера телефона (`+7`). |
| **`form-check`** | `people.html` | Стилизованный чекбокс с меткой (`form-check-input`, `form-check-label`) для подтверждения достоверности сведений и согласия на обработку данных. |
